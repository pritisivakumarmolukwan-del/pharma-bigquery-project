# Pharma Prescription Analytics (BigQuery)

Analysis of Medicare Part D prescriber data (2014) using Google BigQuery.

## Business questions
1. Which drugs are prescribed the most, and which cost the most?
2. Which states and specialties prescribe the most?
3. Who are the top prescribers, and are there cost outliers?
4. What is the brand vs generic share?
5. Where should a sales team focus?

## Dataset
`bigquery-public-data.cms_medicare.part_d_prescriber_2014`
